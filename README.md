💖 Cute Love Website

A fun interactive website where someone answers:

👉 "Do you love me 😡"

- 💖 Yes → shows "I love you too 😘"
- 😈 No → button runs away and shrinks

---

🚀 Live Website

After enabling GitHub Pages, your site will be available at:

https://YOUR_USERNAME.github.io/REPOSITORY_NAME/

---

📦 Setup (GitHub Pages)

1. Create a new repository on GitHub
2. Upload "index.html"
3. Go to Settings → Pages
4. Under Source, select:
   - Branch: "main"
   - Folder: "/root"
5. Save

---

✏️ Edit Website

- Open "index.html"
- Click ✏️ Edit
- Commit changes

Your site updates instantly.
